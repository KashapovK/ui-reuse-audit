# Security Policy

## Reporting a vulnerability

Please do not report security-sensitive findings in a public issue.

Use GitHub's private vulnerability reporting for this repository when available, or contact the repository owner privately through GitHub.

Include only the information needed to reproduce and assess the issue. Do not publish credentials, tokens, private repository contents, internal URLs, or personal data.

## Scope

This repository contains an instruction-only Agent Skill and plugin metadata. It does not ship a runtime service, execute untrusted code, or require credentials as part of its normal operation.

Security issues may still include unsafe instructions, accidental disclosure patterns, dependency or CI supply-chain risks, or packaging behavior that could expose sensitive data.
