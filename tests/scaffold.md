# Scaffold validation

This file exists to keep the test surface explicit during the initial repository scaffold.

Behavioral and activation cases are added by roadmap issue #7 after the skill contract and audit workflow are defined.

For the scaffold issue, verify only that:

- the skill directory is present;
- Agent Skills validation targets `skills/ui-reuse-audit`;
- plugin and skill versions are `0.1.0`;
- the changelog contains the dated `0.1.0` release heading;
- the skills-only manifest does not declare apps, hooks, or MCP servers.
